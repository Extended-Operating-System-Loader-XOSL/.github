# BIOS and UEFI Environments

Modern computers commonly use UEFI firmware, while older hardware may rely on legacy BIOS configurations.

Boot behavior can differ significantly depending on firmware mode, disk partitioning, operating system configuration, and installed boot components.

Users should verify their current system configuration before modifying boot-related settings, particularly when working with multiple drives or operating systems.

---

# Safety and Configuration

Boot configuration directly affects the ability of a computer to start its operating system.

Before making significant changes:

- Back up important files
- Document the current configuration
- Keep recovery media available
- Avoid deleting unknown boot entries
- Verify the correct system partition
- Confirm firmware configuration
- Create recovery options where appropriate
- Apply changes carefully
- Restart only after configuration is complete
- Keep important recovery information accessible

These precautions can make recovery easier if an incorrect configuration prevents normal startup.

---

# Performance

Extended Operating System Loader is focused primarily on system configuration rather than continuous background processing.

Boot-management utilities generally require minimal resources during normal configuration tasks, while actual startup performance depends on hardware, firmware, storage devices, operating system configuration, and installed software.

---

# Troubleshooting

If an operating system no longer appears in the startup menu, first verify that its installation and storage device remain accessible before changing additional boot settings.

For systems that fail to start after configuration changes, use the appropriate operating system recovery environment and restore previously documented settings where possible.

Administrator privileges may be required for modifications involving protected system configuration.
